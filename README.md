Изучить создание графических пользовательских интерфейсов на Python с использованием библиотеки Tkinter, а также встраивание графиков Matplotlib в графическое приложение.

## Выполненные задания

### Средней сложности

#### №2 — Окно с текстовым полем и кнопкой

Создано графическое приложение с текстовым полем для ввода данных и кнопкой.

После нажатия кнопки введённый пользователем текст отображается в окне приложения.

Файл: `text_input_gui.py`

#### №6 — Прогрессбар

Реализовано графическое приложение с прогрессбаром `ttk.Progressbar`.

После нажатия кнопки Start прогресс постепенно увеличивается от 0 до 100 процентов.

Обновление выполняется через метод `after()`, поэтому графический интерфейс не блокируется.

Файл: `progress_bar.py`

#### №8 — Диалог выбора файла

Реализован стандартный диалог выбора файла с помощью `filedialog.askopenfilename()`.

После выбора файла его имя отображается в окне приложения.

Файл: `file_dialog.py`

### Повышенной сложности

#### №4 — График Matplotlib внутри Tkinter

Реализовано приложение, в котором график функции отображается непосредственно внутри окна Tkinter.

Для встраивания Matplotlib используется `FigureCanvasTkAgg`.

Пользователь может изменить коэффициент функции и перестроить график.

Файл: `matplotlib_gui.py`

#### №10 — Локальный чат

Реализован локальный чат для двух пользователей.

Пользователь выбирает отправителя, вводит сообщение и отправляет его в общую область переписки.

Для каждого сообщения отображается время отправки.

Также реализована возможность очистки истории чата.

Файл: `local_chat.py`

## Структура проекта

- `text_input_gui.py` — ввод и отображение текста
- `progress_bar.py` — прогрессбар
- `file_dialog.py` — выбор файла
- `matplotlib_gui.py` — график внутри Tkinter

- `requirements.txt` — внешние зависимости
- `.gitignore` — исключения Git

## Установка зависимостей

Для установки Matplotlib:

```bash
py -m pip install -r requirements.txt
```

Tkinter входит в стандартную поставку Python для Windows и отдельно через `pip` не устанавливается.
